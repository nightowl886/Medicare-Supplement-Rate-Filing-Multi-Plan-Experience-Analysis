# Medicare-Supplement-Rate-Filing-Multi-Plan-Experience-Analysis

## Project Overview
This project evaluates the historical performance and future rate adequacy of UnitedHealthcare’s AARP Medicare Supplement (Medigap) portfolio in California (Group Policy G-36000-4). Using 16 years of regulatory filing data (1998–2013) across standardized plans (Plans A, B, C, etc.) and actuarial assumptions from the official Rate Filing Memorandum, this analysis combines SQL for multi-plan experience studies and Excel for 10-year cash flow projections (2014–2023).

## Key Objectives
- Multi-Plan Experience Study (SQL): Structure raw statutory filing tables into a normalized relational database to compare enrollment shifts, claims severity (PMPM), and loss ratio volatility across different benefit designs.
- Actuarial Cash Flow Projection (Excel): Model future earned premiums and incurred claims (2014–2023) incorporating a 5.0% interest/discount rate, 8.3% annual lapse assumption, and a 5.5% proposed rate increase (effective April 1, 2014).
- Regulatory Compliance & Risk Assessment: Validate whether the projected Lifetime Loss Ratio meets California’s 75.0% statutory minimum under ASOP No. 8, while diagnosing adverse selection risks across plans.
